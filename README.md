# Vortex Digital — Expansão de portfólio

## Pastas
- `vortex-defense/index.html`: jogo 3D independente, executado no navegador. Usa Three.js via CDN e não precisa de npm.
- `dpm-demo/index.html`: simulação fictícia independente, sem dados reais ou conexão ao DPM de trabalho.
- `portfolio/projects-snippet.jsx`: substituição do array `projects` no `main.jsx` da Vortex Digital.
- `portfolio/INSTRUCOES.md`: como inserir os links e o botão de acesso no portfólio.

## Publicação no Render (sem criar pastas no GitHub)
Para cada demo, crie um repositório SEPARADO, copie somente o `index.html` da respectiva pasta para a RAIZ do repositório e publique como Static Site com Build Command `echo 'Site estático'` e Publish Directory `.`. Não altere o projeto Lopes Barber Shop ou o DPM usado no trabalho.

## Limitações
O Vortex Defense é um protótipo inicial; o jogo precisa ser testado em dispositivos reais. O DPM Demo gera respostas pré-escritas, não faz análise de documentos nem usa inteligência artificial. Nenhuma agenda real ou dado interno está conectado.
